# Weather Forecast App

A simple and interactive Weather Forecast Web Application developed using **React.js**, **Bootstrap**, and **OpenWeather API**.  
This project allows users to search for any city and view the current weather details along with upcoming forecast updates in a clean and responsive interface.

## Project Objective

The main objective of this project is to provide users with quick and accurate weather information for different cities using real-time API data.

---

## Features

- Search weather by city name
- Current weather details
- Upcoming forecast cards
- Temperature graph/chart
- Search suggestions for popular cities
- Invalid city alert message
- Responsive design for desktop and mobile
- Clean and user-friendly interface
